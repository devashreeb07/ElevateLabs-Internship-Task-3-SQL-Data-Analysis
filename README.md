# SQL for Data Analysis – E-Commerce Database

## Project Overview
The objective was to use SQL queries to extract, manipulate, and analyze data from a e-commerce database.

## Objective
* Perform SQL-based data analysis on an e-commerce database.
* Practice writing efficient SQL queries.
* Understand relationships between multiple tables using JOIN operations.
* Analyze business data using aggregate functions and subqueries.

## Dataset
A relational e-commerce dataset consisting of the following tables:
* Customers
* Categories
* Products
* Orders
* Order Items
* Payments
  
## SQL Concepts Covered
### Basic Queries
* SELECT
* WHERE
* ORDER BY
* LIMIT
### Aggregate Functions
* COUNT()
* SUM()
* AVG()
* MIN()
* MAX()
### Grouping
* GROUP BY
* HAVING
### Joins
* INNER JOIN
* LEFT JOIN
* RIGHT JOIN
* Multi-table JOIN
### Advanced SQL
* Subqueries
* Views
* Indexes
  
## Business Analysis Performed
* Displayed customer and product information.
* Filtered records using WHERE conditions.
* Sorted products based on price.
* Counted customers and orders.
* Calculated total revenue.
* Computed average product prices.
* Identified the highest and lowest priced products.
* Analyzed orders by status.
* Compared average prices by category.
* Joined multiple tables to retrieve customer order details.
* Identified top customers based on spending.
* Generated revenue reports by payment method.
